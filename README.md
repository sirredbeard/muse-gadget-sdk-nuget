# Muse Gadget SDK for .NET

.NET 11 libraries for building Linux devices with the [Muse Gadget SDK](https://github.com/facebookincubator/muse-gadget-sdk).

This repository is just getting started. The first package will target the Linux SDK in the upstream repository and make it usable from .NET applications.

## Requirements

- .NET 11
- A Linux device supported by the upstream SDK
- A Muse SDK token

## Build

```console
dotnet build
```
