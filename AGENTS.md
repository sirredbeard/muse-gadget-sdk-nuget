# Agent instructions

Start with [`README.md`](README.md) for the public project description and package usage.

Then read [`.github/copilot-instructions.md`](.github/copilot-instructions.md) before inspecting or changing code, workflows, tests, package metadata, or documentation.

The Copilot instructions are the detailed repository guidance. The skill at [`.github/skills/muse-gadget-sdk-linux/SKILL.md`](.github/skills/muse-gadget-sdk-linux/SKILL.md) explains how agents should use the NuGet package in a .NET application communicating with Muse.

If another `AGENTS.md` or instruction file exists in a directory below the repository root, read the more-specific file before changing files in that directory. More-specific instructions add to these instructions unless they explicitly say otherwise.

Preserve existing user edits. Do not move technical detail back into the README when the Copilot instructions are the intended home for it. Do not add co-author metadata to commits.
